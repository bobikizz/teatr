# Приложение «Театр» (Windows Forms)

**Информационная система управления данными театра**, разработанная на платформе .NET Framework 4.7.2 с использованием C# и СУБД Microsoft Access. Приложение включает в себя модули авторизации, добавления данных и расширенного поиска.

## 🚀 Основные возможности

*   **Авторизация пользователей:** Защищенный вход в систему через стартовую форму `LoginForm`.
*   **Управление данными:** Набор специализированных форм (`AddFormA` – `AddFormE`) для добавления и редактирования информации по различным сущностям (например: спектакли, актеры, билеты, залы, режиссеры).
*   **Гибкий поиск и фильтрация:** Набор поисковых форм (`SearchFormA` – `SearchFormE`) для быстрого нахождения нужной информации в базе данных.
*   **Локальная база данных:** Хранение всей информации в файле формата `.accdb` (MS Access).

## 🛠 Технологический стек

*   **Язык программирования:** C# (версия языка 7.3)
*   **Платформа:** .NET Framework 4.7.2
*   **Тип приложения:** Windows Forms (WinExe)
*   **База данных:** Microsoft Access (`teatr.accdb`)
*   **Технология доступа к данным:** ADO.NET (OleDb, Typed DataSet)

## 📋 Системные требования

1.  **Операционная система:** Windows 7 / 8 / 10 / 11
2.  **Среда выполнения:** [.NET Framework 4.7.2 Runtime](https://microsoft.com)
3.  **Компонент БД:** Для корректной работы с базой данных Access требуется установленный движок [Microsoft Access Database Engine 2010/2016](https://microsoft.com) (соответствующей разрядности: x86 или x64).

## ⚙️ Инструкция по сборке и запуску

### Запуск готовой сборки
1. Перейдите в папку проекта `bin\Debug\` или `bin\Release\` (в зависимости от целевой архитектуры: x86, x64 или AnyCPU).
2. Убедитесь, что файл базы данных `teatr.accdb` находится в той же папке, что и исполняемый файл `teatr.exe`.
3. Запустите файл `teatr.exe`.

### Открытие и сборка в Visual Studio
1. Откройте файл проекта `.csproj` или файл решения `.sln` в **Visual Studio 2019 / 2022**.
2. Убедитесь, что в конфигурации сборки выбран нужный режим (`Debug` / `Release`) и разрядность (`x86` / `x64` / `AnyCPU`).
3. Нажмите кнопку **Пуск (Start)** или клавишу `F5` для автоматической сборки и запуска проекта.

## 🗃 Структура проекта и базы данных

*   `Program.cs` — главная точка входа. Сначала вызывает окно авторизации, и в случае успеха открывает главное окно.
*   `LoginForm.cs` — форма для ввода логина и пароля.
*   `Form1.cs` — главное окно приложения (панель управления).
*   `teatrDataSet.xsd` — типизированный набор данных для связи элементов интерфейса с таблицами базы данных.
*   `teatr.accdb` — локальный файл базы данных MS Access, который копируется в выходную директорию при каждой сборке.
*   `App.config` — конфигурационный файл приложения, содержащий строку подключения к БД (`Provider=Microsoft.ACE.OLEDB.12.0`).
